# 驗收

自動測試：四方向輸出尺寸、旋轉四次回原狀、復原/重做、修改後失效確認。
本輪另檢查：未遮蔽頁保留原向量／文字；遮蔽頁移除遮蔽區原文並成為單張 600 DPI 影像；便利貼為獨立 PDF Text 註解，可由 Adobe Acrobat 移動／刪除（須實機驗收）。

需要現場/瀏覽器驗收：
- 原始橫式/直式/原生Rotate/CropBox PDF，在0/90/180/270方向遮蔽對準。
- 中文粗體、底線、編號及英文長字預覽/成果一致；長文字不得被無聲截斷。
- 加備註後旋轉，文字方向及背景一起轉；旋轉後新加備註正向輸入。
- 批次選擇3頁，只影響選中頁；重複套用不新增；一次撤銷/重做完整批次；不同尺寸不預選。
- 確認後任何修改/撤銷/重做均需重確認；一頁未確認整份不能匯出。
- 100文件/多頁PDF清單可操作；大頁超限明確報錯，取消不留下可交付假成果。
- 產生預覽後未修改，匯出使用同一份PDF；修改後不可沿用舊成果。
- 備份後新瀏覽器還原，檔案/物件/方向一致；缺PDF/壞ZIP不新增殘缺案件。
- 本機另存後關閉重開服务，再開啟已存案件成功。
- 斷網冷啟動所有核心流程可用；AI仍不可用。
- 用實際100%列印尺寸核對尺寸線、細線、小字與公差。600dpi不等於向量無損，須實印驗收。
