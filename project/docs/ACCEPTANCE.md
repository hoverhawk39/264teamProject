# 單頁圖面編輯器驗收

自動回歸：`npm run build && npm test && npm run test:ui && python3 -m unittest tests.test_editor_only_server tests.test_local_ai -q`。另檢查 `git diff --check`。測試覆蓋首頁唯一頁面、按鈕橋接、舊 API 不再提供、獨立 PDF 遮蔽／註解及術語翻譯後備；不能取代真實圖面驗收。

使用隔離來源／測試 PDF 逐項實測：

- 首頁只有「圖面編輯區」，上方六個操作按鈕與內部按鈕啟用狀態一致；其它舊頁沒有入口。上傳多頁 PDF、翻頁、遮蔽、便利貼、復原／重做、暫存後重新載入，原進度仍在。
- 翻譯本檔全部頁面：唯一術語直接採資料庫譯文，未命中／多義交本機 AI；失敗逐筆呈現，不偽造譯文；未人工保留的草稿不能匯出。逐頁查 OCR 尺寸、公差、料號等誤辨。
- 預覽與匯出 PDF 數量、頁序、尺寸一致；遮蔽區抽取文字不可復原，便利貼／保留譯文在 PDF 為可編輯註解。測試取消下載過大成果，不應留下誤認為已交付的結果。
- 切換 8765／8766 只作隔離驗證，不會搬移資料。絕不清除舊來源的瀏覽器進度或本機 `local-data/`。
- 真實橫式、直式、旋轉及 CropBox 圖面的幾何、細線、字形、貼紙外觀需實際瀏覽器及紙本列印驗收；100 檔壓力與指定 Acrobat 編輯註解驗收仍待現場進行。

本程式僅 loopback 單機版；正式內網部署前仍須規劃授權、身份驗證、權限、資料保存、併發與安全審查。
